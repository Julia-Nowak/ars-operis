# Ars Operis

Dwujęzyczna (PL/UK) strona rekrutacji kierowców taxi w Trójmieście oraz usług konsultingowych.

## Zawartość

- `index.html` — kompletna, samodzielna strona (HTML + CSS + JS w jednym pliku, bez zależności zewnętrznych).
- Przełącznik języka PL / UA w prawym górnym rogu.
- Formularze zgłoszeniowe (duży w sekcji "Zostaw swoje dane" oraz mini w hero) wysyłają zgłoszenie przez WhatsApp (+48 600 733 799) i otwierają szkic e-maila do biurokierowcow@gmail.com.

## Podgląd lokalnie

Otwórz `index.html` bezpośrednio w przeglądarce — strona nie wymaga budowania ani serwera.

## Hosting

Stronę można hostować za darmo np. przez GitHub Pages (Settings → Pages → branch `main`, folder `/`) lub Netlify/Vercel.
